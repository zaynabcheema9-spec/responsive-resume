# Responsive Resume Web Page

## Lab Task

Create a responsive resume web page using **HTML and CSS only** and deploy it using **GitHub Pages**.

## Project Description

This project is a responsive personal resume webpage created using HTML5 and CSS3. The webpage contains information about education, professional summary, projects, technical skills, and certifications.

The webpage is designed to work on different screen sizes including desktop, tablet, and mobile devices.

## Technologies Used

* HTML5
* CSS3
* CSS Media Queries
* CSS Grid
* GitHub Pages

## Features

* Responsive resume layout
* Professional summary section
* Education section
* Projects section
* Technical skills section
* Certifications section
* 12-column CSS Grid for skills
* Responsive design using media queries
* Mobile-friendly layout
* No JavaScript or external frameworks

## Responsive Design

Media queries are used to change the layout according to the screen size.

### Desktop

The resume uses a wide layout and the skills section is divided using a 12-column grid.

### Tablet

The layout adjusts the resume width and displays skill boxes in two columns.

### Mobile

The resume uses the full screen width and skill boxes are displayed one below another.
